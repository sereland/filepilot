# FilePilot UI 定稿 v3.0

更新时间：2026-10-11。本文是当前界面和交互的实现依据。

## 窗口与视觉

- 默认窗口 **1120 × 700** 逻辑像素，横向比例 1.6:1，启动居中。
- 最小 960 × 600，允许调整大小和最大化；保留 Windows 原生标题栏，标题 FilePilot。
- 侧栏宽 216px；单列规则列表，内容区最大宽度 1040px（含内边距）。页眉、筛选栏与卡片左右对齐。
- 移除工作空间面包屑，窄窗口保留导航入口；规则页固定标题、新建按钮、搜索筛选栏和暂停提示，仅规则列表滚动。其他页面内容及弹窗正文可滚动。
- 单一蓝色品牌色，中性色承担文字、背景、参数和分隔线。
- 浅色：页面 #f7f8fa、侧栏 #f1f3f6、卡片 #ffffff、品牌 #2563eb。
- 深色：页面 #171a20、侧栏 #14171c、卡片 #1e222a、品牌 #78a6ff。
- 字体 Segoe UI Variable / Segoe UI / Microsoft YaHei，不依赖网络字体。
- 标题 26px / 600、卡片名称 15px / 600、正文 14px、表单 13px、辅助文字 12px。
- 控件圆角 6px、卡片 8px、弹窗 12px；卡片悬停只改变边框，动效 150ms，无浮动、呼吸灯或渐变磁贴。
- 可操作元素有中文标签和可见焦点；弹窗支持 Escape、焦点约束和关闭后返回入口，遵守减少动态效果设置。

## 导航与自动整理状态

- 导航顺序：整理规则、规则模板、操作记录、设置。
- 导航不重复显示规则数量，数量在规则页筛选栏展示。
- 主题、版本和本地运行说明在设置中，左下角不放主题快捷入口。
- 左下角只显示当前状态与启停按钮：自动整理运行中 / 自动整理已暂停；没有自动规则时明确说明。
- 正常状态不补充文件夹数量、规则数量、最近整理或活动摘要，历史结果集中在操作记录页。
- 只有实际错误才显示异常及处理入口；不得从无日志推断故障。
- 每条规则的开关决定是否自动整理，关闭后仍可手动预览和执行；全局暂停不改变单规则的自动设置。
- 新规则默认仅手动，既有规则的设置保持不变。

## 整理规则与模板

- 首页副标题：**按条件匹配文件，整理到指定位置。**
- 新建规则位于右上方；支持搜索名称、来源和目标路径，以及全部 / 自动整理 / 仅手动筛选。
- 名称、状态、自动开关在卡片头部；自动状态浅蓝底，手动状态中性灰；全局暂停时显示“自动整理 · 已暂停”。
- 手动规则保持完整对比度，不将整卡降低透明度；来源路径用图标和辅助文字，目标路径与扩展名使用浅灰参数底色。
- 保留“如果 / 那么”，减少重复分隔线；预览整理为次级按钮，编辑为文字入口，复制及删除在更多菜单。
- 卡片底部操作靠右，左侧显示执行状态：无实际操作记录时“暂未执行”，有记录时显示真实最近执行时间。查询完整日志，不受记录页条数上限影响；撤销后保留执行过的状态。
- 双击卡片空白或文本区域打开编辑，保留明确的“编辑”入口；开关、预览按钮及更多菜单区域不触发双击编辑。
- 模板有独立页面，副标题：**选择模板，设置来源和目标文件夹，保存后先预览。**
- 首批模板为图片归档、PDF 文档整理、发票报销；发票使用复制动作。
- 模板只预填条件与动作，来源和目标由用户选择，不写入开发者路径；保存返回规则页，取消回到模板页。
- 模板说明与页头标题左对齐，不在卡片下方重复追加段落。

## 规则编辑器

- 名称、来源、匹配条件、执行动作、自动整理开关及实时自然语言摘要依次排列。
- 来源和目标支持输入 / 粘贴以及 Windows 原生文件夹选择，保留多个来源文件夹能力。
- 条件类型和参数同一行；扩展名为空时是普通“选择文件类型”控件，不放大空框或蓝色加号入口。
- 条件和动作类型保留原生选择框的键盘行为，箭头、边框、高度和间距与右侧文件类型控件统一。
- 文件类型选择弹窗支持搜索、图片 / 文档 / 压缩包 / 音视频分组多选与自定义；控件返回已选扩展名摘要。
- 同一扩展名条件内是 OR，多条件之间是 AND。
- 保留扩展名、关键词、大小、日期四种条件，移动、复制、重命名、回收站四种动作，以及多个条件 / 动作。
- 添加条件及动作使用收敛的菜单或选择框；必填项目标 *。提交时同时校验名称、各来源、条件参数与动作参数，错误字段红框并就近说明，自动聚焦并滚动到第一处错误；修改后同步解除已修正字段的错误提示。
- 新建和编辑规则弹窗点击外部空白处不关闭，避免意外丢失已填内容；保留关闭、取消与 Escape 入口。文件类型选择、预览等弹窗维持原交互。
- 新规则默认仅手动；开启自动整理时说明全局暂停是否阻止当前规则运行。

## 预览、记录及反馈

- 预览显示文件、操作、目标位置及完整来源 / 目标路径。
- 默认全选，可逐文件取消或全选/全不选；部分勾选时表头显示半选状态。同一文件的全部动作共用勾选项，不能单独排除其中一个动作。
- 确认按钮显示已选文件数，未选任何文件时禁用。仅影响本次手动整理，自动规则仍按原条件运行。
- 执行接口必须接收明确的选中文件名单；后端重新扫描校验规则并只保留名单内的文件，未勾选及预览后新增的文件不纳入本次执行。
- 文件数按不同源文件统计；一个文件有多个动作时另行标注操作数。
- 手动确认前不修改文件，执行中禁用关闭及重复提交。
- 执行与撤销反馈使用应用内提示，提供查看记录入口；历史按批次折叠展示。
- 不承诺回收站动作可通过应用内撤销；按实际后端支持提示回收站恢复方式。
- 正式应用使用真实接口，不包含设计稿的示例状态切换器。
- 保存 / 修改自动规则后同步实际监控文件夹集合，避免新增文件夹未监听。
