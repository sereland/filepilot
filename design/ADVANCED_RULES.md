# 复杂规则：条件组合与动态归档

## 本轮用户能力

- 条件组支持全部满足、任一满足、排除，可嵌套；空组不匹配并禁止保存。
- 名称支持包含、不包含、等于、开头是、结尾是，不区分大小写，支持中文；针对完整名称，包括文件扩展名。
- 文件大小支持大于、小于、闭区间，界面单位 MB。
- 创建时间和修改时间支持最近 N 天、距今至少 N 天。按实际持续时间计算（一天 24 小时），无法读取所需时间时不匹配，排除组也不能把缺失时间误判成匹配。
- 移动/复制分为目标根文件夹与可选子文件夹模板；根目录可直接选择。模板支持 `{year}`、`{month}`、`{day}`、`{date}`、`{datetime}`、`{ext}`、`{name}`。
- 重命名与归档分别选择执行日期、文件创建日期或修改日期。移动/重命名之后的名称变量使用当前名称，文件日期使用来源的原始元数据。
- 普通文件连续动作按顺序执行；移动、重命名后继续使用新路径，复制后仍处理原文件。回收站须为最后一个动作。某文件失败后停止它的后续动作，其他文件继续执行。

可直接配置的示例：

> PDF，名称包含“发票”或“收据”，排除“草稿” → 按修改日期重命名为 `{date}_{name}.{ext}` → 移动到“财务”文件夹的 `{year}/{month}` 子目录。

前后端共用示例数据见 `tests/fixtures/invoice-rule.json`。

## 依赖与表达模型

- 前端采用 React Query Builder 8.12.0，复用分组、组合与编辑状态管理，使用现有中文下拉及文件类型选择控件。项目 `.npmrc` 跳过不需要的数据库等 peer 依赖，锁文件保证 CI 使用相同安装结果。
- Rust 使用 datalogic-rs 5.8.1，关闭可选功能，编译一次条件后对扫描结果求值。该版本最低要求 Rust 1.98，本地使用 1.99。
- 用户规则仍保存为有类型的条件模型：旧的四种条件可直接读取，新增 `group`、名称比较、大小及时间条件；新格式需要新版应用识别。编辑器转换到该模型，Rust 转换为标准 JSONLogic，由成熟求值库处理组合逻辑。
- 不直接照搬编辑器导出的非标准 `startsWith`/`endsWith`。开头/结尾匹配用标准 `substr` 与严格比较表达；日期先转换为秒数，不依赖前后端不同的日期解析规则。
- 条件组限制最多 4 层、每组 100 个条件；文件动作最多 20 个。空条件、未知字段/运算符、缺失必需时间不放宽匹配。

参考：[React Query Builder 导出及兼容说明](https://react-querybuilder.js.org/docs/utils/export#jsonlogic)、[JSONLogic 标准运算](https://jsonlogic.com/operations.html)、[datalogic-rs](https://github.com/GoPlasmatic/datalogic-rs)。

## 预览、选择与日志

- `PlanItem.src` 始终是原始选择对象，`input_src` 是当前步骤预计使用的路径；预览将连续动作放在同一勾选项内，同时显示每一步实际目标。
- 来源排序、目标名预留同时考虑本批文件与磁盘已有目标。同名加编号，取消勾选其他文件不改变本文件的预览名称。ZIP 仍在分组前过滤选择名单。
- 本次预览的执行日期/时间由后端固定，避免 `{datetime}` 等变量在确认时改变文件名。确认时重新扫描并比较所选完整流程，计划或多动作内容校验变化时要求重新预览；前端传来的动作/路径不作为执行依据。
- 连续文件流程携带内容校验，执行前确认来源内容未变化；实际目标被占用时停止并要求重新预览。错误也写入操作记录。
- 日志 `src` 保存该步骤真实来源；新增可选 `origin_src` 用于按原始对象计数，旧日志回退使用 `src`。多个动作在卡片、侧栏和记录页只算一个文件。
- 新增模板只允许相对子目录，拒绝绝对路径、`..`、Windows 非法/保留名称和未知变量。重命名只产生单个有效名称。

## 撤销与监控

- 仍按批次逆序撤销，不引入任意历史记录撤销或按文件选择撤销。
- 普通文件流程在撤销前检查依赖链；多动作流程另有内容校验。连续流程目标内容已变、目标丢失、中间路径被占用时不开始恢复此文件；撤销中某一步失败后，停止该文件更早的动作。单动作仍沿用原有内容处理语义。
- 原始来源被占用仍可恢复到加编号的位置；不会把被占用的中间路径当作本流程的文件移动。
- 成功复制的来源、移动/重命名的现有目标和失败后保留的来源进入状态保护，避免自动整理反馈循环。对象修改后或手动确认可再次处理；撤销继续使用现有恢复保护。
- 普通文件流程沿用 JSONL 日志，没有 ZIP 更新的事务恢复能力；失败后保留已成功步骤，用户可通过批次撤销恢复。新增年月子目录在撤销后保留，避免移除用户新放入的内容。
- 文件夹规则仍为一个动作，ZIP 更新仍独立使用；新增条件组和日期模板可用于符合既有目录边界的动作。

## 本轮边界与后续

时间条件仍在文件夹变化或手动预览时检查。静置文件达到天数后不会自行产生事件；规则编辑器明确提示需手动预览。**定期扫描、规则优先级与匹配后停止后续规则留到下一轮**，与递归整理内部文件、正则和任意日期区间分别实施。

本地验证使用真实 Windows 文件操作和 8.3 短路径临时目录：82 项核心测试（52 项原有、18 项目录、12 项复杂规则），20 项前端测试以及 TypeScript/Vite 构建。浏览器用正式组件和模拟接口验证分组编辑、红框校验、保存模型、小数输入、模板与整文件选择，以及 1120 × 700 / 960 × 600 布局；不替代原生验收。当前桌面依赖缓存不完整，原生构建由既有 GitHub Actions 完成。
